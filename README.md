# S.C.A.C.I. — Sistema de Controle e Auxílio para Corretor Independente

Projeto acadêmico desenvolvido no curso de **Bacharelado em Sistemas de Informação do IFBA — Campus Vitória da Conquista-BA**.

O **S.C.A.C.I.** é um sistema voltado ao gerenciamento das atividades de um corretor de imóveis independente, buscando centralizar e organizar informações relacionadas a **clientes, imóveis, vendas, visitas, corretores e funcionários**.

O projeto teve início no **4º semestre do curso**, sendo desenvolvido simultaneamente nas disciplinas de **Banco de Dados I** e **Análise e Modelagem de Sistemas**. No **5º semestre**, o projeto terá continuidade nas disciplinas de **Banco de Dados II, Processos de Desenvolvimento de Software e Programação Web II**, dando sequência ao trabalho realizado anteriormente.

## Disciplinas

### 4º semestre

* Análise e Modelagem de Sistemas
* Banco de Dados I

### 5º semestre

* Banco de Dados II
* Processos de Desenvolvimento de Software
* Programação Web II

## Estrutura do projeto

* `analise-modelagem/` — documentos, diagramas UML e protótipos desenvolvidos na disciplina de Análise e Modelagem de Sistemas.
* `banco-dados/` — modelos, documentação e scripts relacionados ao banco de dados desenvolvido no projeto.
* `processos-desenvolvimento-software/` — materiais e atividades desenvolvidos na disciplina de Processos de Desenvolvimento de Software.
* `programacao-web-ii/` — desenvolvimento da aplicação web do projeto.

## Status

**Em desenvolvimento.**

O projeto será ampliado e aprimorado ao longo do 5º semestre, incorporando as etapas de desenvolvimento de software, programação web e novos componentes de banco de dados.
